## About

This project is a simple and interactive hydration tracker. The interface helps users monitor their daily water intake by selecting small cups throughout the day. As each cup is filled, the big cup updates in real time to show both the completed percentage and the remaining liters.

This project focuses on DOM manipulation and visual feedback, making it a great practice project for beginners who want to improve JavaScript fundamentals with a clean and practical UI.

## Features

- Track daily water consumption visually
- Click to fill or unfill small cups
- Dynamic update of progress percentage
- Automatic calculation of remaining amount
- Responsive and clean layout

## How It Works

Each small cup represents a fixed portion of water. When you click a cup:

1. The selected cup and all previous cups become filled.
2. Clicking a filled cup can reduce the total.
3. The large progress container updates instantly:
	- **Top section:** Remaining liters
	- **Bottom section:** Percentage completed
